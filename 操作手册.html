📘 LabelFast 操作手册

文本命名实体识别 · 关系抽取 · 图像特征标注 一体化平台

版本 v1 · 2026年6月

1. 系统概述

🏗️ 系统架构
图：LabelFast 系统整体架构
🎯 三大核心功能

📝 文本标注平台

  • 命名实体识别（NER）标注
  • 实体关系抽取（RE）标注
  • 拖拽上传 TXT，自动切分
  • 可视化关系连线（SVG 贝塞尔曲线）
  • JSON / JSONL / CSV 多格式导出

  • 问答标注：用户指令 → 助手回答
  • 框选标注：图片上拖拽绘制矩形框

  • 支持子目录递归扫描图片
  • 一键打包导出 ZIP（标注+图片）

🔐 用户认证

  • JWT Token 认证机制
  • 管理员通过 backend/users.xlsx 管理账号
  • 不提供自助注册功能

2. 登录流程

图：登录页面布局
  • 打开浏览器，访问系统地址（如 http://localhost:8000）→ 自动跳转至登录页
  • 输入账号和密码（账号由管理员在 backend/users.xlsx 中预先配置）
  • 点击"登录"按钮 → 验证通过后自动进入文本标注平台首页
  • 右上角可退出登录或切换到图像标注平台
    • 💡 提示：系统使用 JWT 令牌认证，令牌存储在 sessionStorage 中，关闭浏览器后需重新登录。

    3.1 页面布局总览

    图：文本标注平台页面布局

    3.2 项目配置模块

    操作说明
    选择已有项目 ▼ 下拉框列出所有已创建项目，选中即可加载。加载后自动同步项目数据、标签和待标注文档。
    创建新项目 在输入框中填写项目名称，点击创建。新项目会分配唯一的 UUID，并自动创建项目目录结构。
    保存 将当前项目的所有数据（标签配置、文档、标注结果）全部保存到后端。保存后文档 ID 会与后端同步。
    打包导出 一键导出整个项目为 ZIP 压缩包，包含 JSON、JSONL、CSV 三种格式（参见 3.6 导出）。
    清空数据 清空项目的标签配置和所有待标注对象。此操作不可撤销，系统会弹出确认框。
    删除项目 彻底删除项目及其所有数据。此操作不可恢复，系统会弹出二次确认。

    3.3 标签配置模块

    🏷️ 配置实体标签与关系类型

    实体标签（Entity Labels）

    在"实体标签"输入框中填入标签名，多个标签用 逗号、分号 分隔。

    关系类型（Relation Types）

    在"关系类型"输入框中填入关系名，多个类型用 逗号、分号 分隔。

    💡 批量导入标签/关系：点击"从 TXT 文件导入"，选择一个 .txt 文件。文件格式支持 LABELS: 和 RELATIONS: 标题行来自动分类。

    3.4 文本导入与切分

    📥 三种切分模式
    模式行为生成标注对象数适用场景
    原文 整篇不切分，全文作为 1 条标注对象 1 短文本、完整文档分析、整体情感分析
    段落 按空行分段，每段作为 1 条标注对象 3~10 段落主题提取、分段情感分析、内容结构化
    句子 按句末标点（。；！？!?;）切分，每句 1 条 10+ 句子级实体识别、语法分析、细粒度标注

    导入方式

  • 拖拽 .txt 文件到"待标注对象"模块的拖拽区域
  • 点击"选择文件"按钮，从文件管理器中选择 .txt 文件（支持多选）
  • 系统自动检测编码（UTF-8 / GBK / UTF-16），导入后按当前选中的切分模式拆分
    • 💡 提示：可以多次导入不同文件，所有文本都会追加到当前项目的待标注列表中。单文件大小限制 10MB。

    3.5 标注操作

    ✏️ 实体标注（NER）
  • 用鼠标划选标注工作区中的文本片段
  • 弹出标签选择弹窗，点击标签名（或按数字键 1-9）
  • 被选中的文本会覆盖一层半透明彩色底纹，颜色由标签决定
    • 图：实体标注效果示意 —— 彩色底纹标识实体，"担任"关系连线连接"张伟"和"机加车间"
    🔗 关系标注（Relation Extraction）

    关系标注用于连接两个已标注的实体，表达它们之间的语义关系。

  • 拖拽连线：鼠标按住一个已标注实体 → 拖动到另一个实体上松开
  • 点击连线：先点击实体 A 选中（蓝色描边）→ 再点击实体 B → 弹出关系选择弹窗
  • 右键循环选中：右键点击重叠区域，循环切换已标注实体
  • 删除关系：鼠标悬停在关系线上，线条高亮，点击关系线可修改或删除
    • 图：拖拽连线创建关系。蓝色描边表示被选中的实体，紫色弧形连线表示关系

    3.6 文本标注快捷键

    快捷键功能
    1 - 9选中文本后，快速选择第 1~9 个实体标签
    Ctrl + 1-9在关系选择弹窗中，快速选择第 1~9 个关系类型
    Space保存当前标注并跳到下一篇（等同"保存并下一篇"按钮）
    ← / →切换上一篇 / 下一篇待标注对象
    Delete删除当前选中的标注（实体或关系）
    Esc关闭弹窗 / 取消选中 / 退出设置面板
    Ctrl + Z撤销上一次操作（实体标注 / 关系标注）

    4.2 项目配置模块

    操作说明
    选择已有项目 ▼ 从下拉框选择已创建的项目。切换项目时会自动保存当前项目的标注数据。
    新建项目 输入项目名称后点击创建。系统会自动创建 projects/项目名/images/ 目录结构。
    📁 图片存放位置 新建项目后，需将待标注的图片放入 projects/项目名/images/ 文件夹中。支持子目录递归扫描。
    💾 标注结果保存位置 问答和框选标注结果自动保存到 projects/项目名/ 文件夹下的 标注结果_qa.jsonl 和 标注结果_boxes.jsonl。
    保存当前项目 保存项目标签列表和所有标注数据（问答 + 框选）到后端。
    删除项目 删除项目及其所有标注数据和目录。不可恢复。

    4.3 问答标注模式

    💬 问答标注操作流程

    问答标注适用于 视觉问答（VQA）、图像描述生成 等 AI 训练场景。每条标注记录包含「用户指令」和「助手回答」两部分。

  • 切换到问答标注模式（点击右侧面板顶部的"问答标注"标签）
  • 在左侧图片列表中选择一张图片（或使用翻页按钮）
  • 在 User Input（用户指令） 文本框中输入问题或指令。系统默认填入"详细描述这张图片。"
  • 在 Assistant Output（助手回答） 文本框中输入模型期望的标注回答
  • 点击 "保存并下一张" 按钮（或按 Ctrl+Enter）
    • 💡 提示：User Input 中会自动附加 <image> 标记到末尾，用于标识该对话关联图片。无需手动添加。
    图：问答标注示例 —— 用户指令 + 助手回答

    4.4 框选标注模式

    📦 框选标注操作流程

    框选标注（Bounding Box Labeling）适用于目标检测、物体定位等计算机视觉训练场景。

  • 切换到框选标注模式（点击右侧面板顶部的"框选标注"标签）
  • 定义标签列表：在标签输入框中输入标签名，按 Enter 添加。
    1 人物 2 车辆 3 建筑 4 标志
  • 选择一个当前标签（点击标签芯片选中，或按数字键 0-9 快速选择）
  • 点击"开始框选标注"按钮进入绘制模式
  • 在图片上按住鼠标左键并拖拽，创建矩形标注框
  • 松开鼠标确认框选，点击 "保存当前图片框标注"（或按 空格键）
    • 图：框选标注效果示意 —— 红色框标注"人物"，紫色框标注"车辆"

    4.5 导出功能

    📦 数据导出

    图像标注平台 — 打包导出 ZIP

    图像标注平台支持三种导出模式，均以 ZIP 压缩包形式下载：

    导出按钮模式包含内容
    📦 打包导出问答标注qa问答标注 JSONL + 已标注图片
    📦 打包导出框选标注box框选标注 JSONL + 已标注图片
    — (通过 API 调用)all问答 + 框选标注 JSONL + 已标注图片 + README

    文本标注平台 — 打包导出 ZIP

    点击打包导出按钮，一次性导出包含 JSON、JSONL、CSV 三种格式的 ZIP 压缩包。

    💡 提示：导出时 ZIP 文件名包含项目名称和时间戳，方便追溯。导出包内包含 README.txt 记录标注数量统计。

    5. 附录：部署说明

    🚀 快速启动

    启动后端

    cd backend
pip install -r requirements.txt
python server.py

    后端默认启动在 http://localhost:8000（端口自动检测，若占用则递增）。

    启动前端

    cd frontend
npm install
npm run dev

    前端开发服务器启动后，访问终端输出的本地地址即可。生产环境下，前端构建后的 dist/ 目录由 FastAPI 后端统一托管。

    账号管理

    • 管理员维护 backend/users.xlsx 文件
    • 修改后重启后端服务生效
    • 系统不提供自助注册功能
    🐳 Docker 部署（离线环境）
    1. 将 multi-view-ontology-tool.tar 和 docker-compose.offline.yml 拷贝到服务器
    2. 加载镜像：docker load -i multi-view-ontology-tool.tar
    3. 启动服务：docker-compose -f docker-compose.offline.yml up -d
    4. 访问 http://服务器IP:3001
    💡 注意：离线部署时，需要确保 compose 文件中的端口号（默认 3001）、volumes 路径和 :z SELinux 标签正确配置。详见 Docker打包规范.md。
