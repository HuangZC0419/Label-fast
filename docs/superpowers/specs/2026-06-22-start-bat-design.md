# start.bat 设计文档

> 日期: 2026-06-22 | 状态: 待确认

## 1. 目标

在仓库根目录新增 `star.bat`，双击后可一键启动前后端开发服务。

## 2. 设计决策

| 维度 | 决定 |
|------|------|
| 启动方式 | 双窗口启动 |
| 路径策略 | 使用脚本所在目录作为项目根目录，不写绝对路径 |
| 后端端口 | 继续使用 `backend/server.py` 现有自动探测逻辑 |
| 前端端口 | 由 `star.bat` 从 `5173` 开始探测空闲端口并传给 Vite |
| 前端命令 | `npm run dev -- --host 0.0.0.0 --port <port>` |
| 后端命令 | `python server.py` |

## 3. 脚本行为

### 3.1 根目录定位

- 使用 `%~dp0` 获取 `star.bat` 所在目录
- 使用相对路径进入：
  - `backend\`
  - `frontend\`

### 3.2 后端启动

- 新开一个终端窗口
- 进入 `backend\`
- 执行 `python server.py`
- 由后端自身处理端口冲突

### 3.3 前端启动

- 在 `star.bat` 中通过 PowerShell 检测本地 TCP 端口是否空闲
- 从 `5173` 开始递增，找到第一个可用端口
- 新开一个终端窗口
- 进入 `frontend\`
- 执行 `npm run dev -- --host 0.0.0.0 --port <可用端口>`

## 4. 错误处理

- 如果 `backend\` 或 `frontend\` 目录不存在，窗口提示错误并暂停
- 如果系统没有 `python` 或 `npm`，命令执行失败时保留窗口，便于查看报错
- 如果前端端口探测失败，回退使用 `5173`

## 5. 改动范围

- 新增 `star.bat`
- 不修改现有后端与前端业务代码
