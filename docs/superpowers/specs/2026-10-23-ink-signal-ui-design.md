# LabelFast Ink & Signal UI 设计方向

- 日期：2026-10-23
- 状态：已确认并实施
- 适用：登录页、全局外壳、文本标注页、图像标注页、大模型问答标注页

## 1. 视觉概念

**Ink & Signal**：以暖纸色作为工作画布，深墨色作为导航骨架，朱砂橙作为唯一强调色。
目标是让标注工具具备编辑出版物的质感，而不是通用企业后台的观感。

关键词：暖白、墨色、朱砂橙、衬线展示字、细线、留白、暖色阴影、轻微颗粒、克制动效。

明确避免：蓝紫 AI 渐变、纯黑背景、过多圆角、白卡 + 灰边 + 黑阴影的模板化组件、Enter 默认字体感。

## 2. 设计令牌

| 类别 | 取值 |
|---|---|
| 画布 | `#F6F3EC` / `#EFEBE2` |
| 表面 | `#FFFDF9` / `#FFFFFF` / `#F2EEE6` |
| 墨色 | `#17181B` / `#3E4147` / `#6E727A` / `#9A9DA3` |
| 细线 | `#E2DCCF` / `#D2CABA` |
| 强调 | `#E4572E` / `#C44722` / `#FBE8E1` / `#8E2F14` |
| 导航 | `#141619` / `#1C1F24` |
| 语义 | 成功 `#2F7D5B`、警示 `#A9761E`、危险 `#B5403A`、信息 `#3B6E8F` |

字体：

- 界面：Geist Variable
- 展示：Instrument Serif（用于英文词标、eyebrow、强调句）
- 数字/代码：Geist Mono Variable，启用 `font-variant-numeric: tabular-nums`

圆角：控件 9-12px，容器 16-22px，大卡片 22-28px。
阴影：统一使用带暖色底色的低透明度阴影，避免纯黑投影。

## 3. 布局与组件

- 左侧导航：84px 深墨竖向图标栏，三项（文本 / 图像 / 问答），激活项朱砂橙强调条。
- 顶部栏：64px，暖白半透明 + 背景模糊，Instrument Serif 品牌词标，当前模块 eyebrow。
- 登录页：深墨品牌面板 + 暖纸表单面板，55/45 分栏，大号衬线字标与示例高亮段落。
- 文本页：左侧 320px 项目/标签栏 + 248px 待标注对象列；右侧纸张画布最大约 1280px，正文约 96ch 阅读宽度；未选择文档时画布与文档列表均显示编辑式空状态。
- 图像/问答页：左侧项目与图片列表，中部点阵画布，右侧 360-390px 标注面板；小图以 FIT 方式等比放大（最多 6×），大图保持适配，框坐标仍按自然像素换算。
- 提示：全局右下角 Toast 替代 `window.alert`；破坏性操作保留原生确认。
- 空状态：细线图形 + Instrument Serif 英文短句 + 中文说明，不使用单行灰字。

## 4. 动效与可访问性

- 过渡 180-240ms，使用 `transform` / `opacity`；页面切换 opacity + 6px 位移。
- 按钮 hover 上浮 1px、active 轻微缩放；模态框 fade + scale。
- 所有交互元素提供 `:focus-visible` 外环。
- 支持 `prefers-reduced-motion: reduce`。
- 状态提示具备 `aria-live`；颜色对比度满足正文可读性。

## 5. 约束

- 只改视觉与提示交互，不改变标注、项目、导入、保存、导出、快捷键等业务逻辑。
- 保持离线可用：字体通过 `@fontsource` 本地打包，不引用外部 CDN。
- 保留自动化回归依赖的选择器与关键文案。
