# start.bat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a root-level `star.bat` that starts backend and frontend in separate windows using relative paths and automatic port selection.

**Architecture:** The batch file uses `%~dp0` as the project root so it works from any location without hard-coded absolute paths. Backend startup delegates port conflict handling to `backend/server.py`, while frontend startup probes for an available Vite port starting from `5173` via PowerShell and passes it to `npm run dev`.

**Tech Stack:** Windows batch, PowerShell, Python backend, Vite frontend

---

### Task 1: Create Batch Launcher

**Files:**
- Create: `star.bat`

- [ ] **Step 1: Add the batch file with relative-path startup logic**

```bat
@echo off
setlocal EnableExtensions EnableDelayedExpansion

set "ROOT_DIR=%~dp0"
if "%ROOT_DIR:~-1%"=="\" set "ROOT_DIR=%ROOT_DIR:~0,-1%"

set "BACKEND_DIR=%ROOT_DIR%\backend"
set "FRONTEND_DIR=%ROOT_DIR%\frontend"
set "FRONTEND_PORT=5173"

if not exist "%BACKEND_DIR%\server.py" (
    echo [ERROR] backend\server.py 不存在
    pause
    exit /b 1
)

if not exist "%FRONTEND_DIR%\package.json" (
    echo [ERROR] frontend\package.json 不存在
    pause
    exit /b 1
)

for /f %%P in ('powershell -NoProfile -ExecutionPolicy Bypass -Command "$port=5173; while ($true) { $busy = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue; if (-not $busy) { Write-Output $port; break }; $port++ }"') do (
    set "FRONTEND_PORT=%%P"
)

if not defined FRONTEND_PORT set "FRONTEND_PORT=5173"

echo [INFO] Backend dir: %BACKEND_DIR%
echo [INFO] Frontend dir: %FRONTEND_DIR%
echo [INFO] Frontend port: %FRONTEND_PORT%

start "LabelFast Backend" cmd /k "cd /d "%BACKEND_DIR%" && python server.py"
start "LabelFast Frontend" cmd /k "cd /d "%FRONTEND_DIR%" && npm run dev -- --host 0.0.0.0 --port %FRONTEND_PORT%"

endlocal
```
