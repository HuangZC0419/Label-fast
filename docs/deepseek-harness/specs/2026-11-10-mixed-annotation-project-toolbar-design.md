# 混合标注项目管理与工具栏二次重构

- 日期：2026-11-10
- 状态：已确认
- 前置：`2026-11-09-mixed-annotation-sidebar-design.md`
- 范围：`frontend/src/modules/mixed-annotation/` 纯前端排版与信息层级
- 不改动：上传/导入/轮询/转换、标注与 Markdown 保存、PDF 预览与同步滚动、图表创建/编辑/删除的数据流

## 1. 目标

1. 项目管理（切换、新建、重命名、配置、删除）全部集中到顶栏，取消左侧项目卡片。
2. 项目配置与文档转换参数合并为一个设置面板，消除分散入口。
3. 工作区控制项（标注 / 编辑 Markdown / PDF 预览 / 同步滚动）统一为同级 chip。
4. 删除顶部重复的「图片/表格标注」入口，截图统一从 PDF 预览面板进入。
5. 「保存标注」与「导出 ZIP」在工具栏右侧并列，两个独立动作。

## 2. 顶栏

```text
[项目 ▾] [＋] [⋯]    [● 当前文件 · 状态] ······   [● 本地工具 在线]
```

- `⋯` 菜单项：重命名项目 / 项目配置 / 转换参数 / 分隔线 / 导出项目 ZIP / 分隔线 / 删除项目（危险色）。
- 无项目或 `menuDisabled`（保存、导入、扫描中）时菜单按钮禁用。
- 点击菜单项、点击外部、按 Esc 关闭菜单。
- 移除顶栏原有的「导出 ZIP」按钮与 `export` 事件。

## 3. 左侧栏

只保留两块：

```text
┌ 导入 Import ─────────────┐
│  拖拽区                   │
│ [选择文件] [选择文件夹]    │
│  进度 / 队列统计           │
├ 文件 (N)           [刷新] ┤
│ ... 单一滚动 ...          │
└──────────────────────────┘
```

- 删除 `ProjectPanel.vue` 的使用与文件。
- 导入区移除齿轮按钮与 `ConversionSettingsDialog.vue`，该文件删除。

## 4. 统一设置弹窗

`ProjectSettingsDialog.vue`，一个面板包含两块：

```text
┌ 项目设置 / 新建项目 ─────────────── × ┐
│ 项目信息                              │
│  名称      [..................]       │
│  实体标签  [..................] N 个  │
│  关系类型  [..................] N 个  │
│                                       │
│ 转换参数                              │
│  ☑ 表格识别  ☐ 公式识别   DPI [200]  │
│  公式识别在 CPU 下较慢…                │
├───────────────────────────────────────┤
│                       [取消] [保存]   │
└───────────────────────────────────────┘
```

- `mode: 'create' | 'edit'`；创建时标题「新建项目」、按钮「创建项目」。
- `focusSection: 'rename' | 'project' | 'conversion'`：
  - `rename` / `project` → 打开后聚焦名称输入框；
  - `conversion` → 滚动并聚焦转换参数区块。
- 底部「保存」一次提交项目配置 + 转换参数；父组件先 PATCH 项目，成功后应用转换参数并关闭弹窗。
- 父组件的 `createProject` / `saveProject` 改为返回 `Promise<boolean>`，供弹窗关闭时机判断。
- 复用全局 `.field` / `.mx-input` / `.check` / `.mx-btn` 样式；不使用 Teleport（保持 `.mx-root` 作用域）。
- 焦点管理：打开聚焦、Tab 循环、关闭恢复焦点、Esc 关闭、屏蔽背景 Ctrl+S。

## 5. 删除确认

新增 `ConfirmDialog.vue`（自绘）：

```text
┌ 删除项目「国标3」？ ──────────────── × ┐
│ 将同时删除 12 个文件、5 个标签、       │
│ 3 种关系，以及全部标注记录和图表截图。  │
│ 此操作不可恢复。                        │
├─────────────────────────────────────────┤
│                       [取消] [删除项目] │
└─────────────────────────────────────────┘
```

- 影响范围使用当前 `files.length` 与项目的标签/关系数量动态生成。
- 删除中禁用两个按钮并显示「删除中…」。
- 删除成功后关闭弹窗；失败保留弹窗并显示错误提示。

## 6. 工作区工具栏

```text
项目 / 文件名

[● 标注] [○ 编辑 Markdown] [○ PDF 预览] [● 同步滚动]      [保存标注] [导出 ZIP]
```

- 四个控制项统一 `.mw-control`：同高 32px、同内边距、同圆角、同字号、同间距。
- 状态色：
  - 当前模式：深墨实心 + 反白文字 + 亮状态点；
  - 开关开启：朱砂浅底 + 朱砂描边/文字 + 朱砂状态点；
  - 未激活：白底 + 细边 + 灰色状态点。
- 四个按钮统一使用 `aria-pressed` 表示当前状态（模式互斥，开关独立）。
- 删除顶部「图片/表格标注」按钮与 `startFigureCapture`；截图只从 PDF 预览面板头部的「截图」进入，拖框后在 `FigureDialog` 选择「图 / 表」。
- 右侧操作组 `.mw-publish`：`[保存标注]`（主按钮）与 `[导出 ZIP]`（次按钮）并列；导出通过 `export` 事件交给父组件 `exportProject`。
- `Ctrl+S` 仍只保存，不导出。

## 7. 验收标准

1. 顶栏是唯一的项目管理入口；左侧没有项目卡片。
2. 「⋯」菜单可完成重命名、项目配置、转换参数、导出项目 ZIP、删除项目。
3. 无文件打开时，仍可从「⋯」菜单导出整个项目 ZIP。
4. 项目配置与转换参数在同一个设置面板内保存。
5. 删除前显示文件数、标签数、关系数及不可恢复提示。
6. 工具栏四个控制项同尺寸同级；「保存标注」与「导出 ZIP」并列。
7. 顶部不再有「图片/表格标注」；PDF 预览内的「截图」可正常创建图/表。
8. `npm run typecheck` 与 `npm run build` 通过；上传、轮询、保存、预览、同步滚动行为不变。

## 8. 不做

- 不新增后端接口。
- 不做单文件导出（导出 ZIP 为整个项目，现有接口）。
- 不改移动端专属重排。
